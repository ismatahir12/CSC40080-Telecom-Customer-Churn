# Telecom Customer Churn Prediction
Project Overview
This project investigates customer churn in a telecommunications company using statistical analysis and machine learning. The aim is to identify factors associated with customers leaving and compare models that can help identify customers at risk of churn.

Dataset
The project uses the IBM Telco Customer Churn dataset. The data was cleaned and prepared for analysis, including handling missing values, removing the customer ID, encoding categorical variables and splitting the data into training and testing sets.

Methods
Exploratory data analysis
Chi-square test of association
Welch’s t-test
Logistic regression
Decision tree classification
Model evaluation using accuracy, precision, recall, F1-score and ROC-AUC
Main Findings
The analysis found that contract type and customer tenure were associated with churn. Logistic regression achieved an ROC-AUC of approximately 0.835, compared with 0.818 for the decision tree.

Limitations
The dataset represents a snapshot of customer behaviour. The analysis identifies associations rather than proving causation, and the findings may not generalise to every telecommunications company.
